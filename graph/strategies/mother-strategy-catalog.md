# G1 mother strategy catalog

Status: **normative draft**

ChineseTutor should expose many Knowledge/Ability nodes and many authentic TaskTypes, but only a small number of reusable **Strategy** nodes.

A mother strategy is a reusable decision/procedure that coordinates multiple operations and can be:

- explicitly prompted;
- faded;
- independently invoked;
- automated;
- transferred across TaskTypes.

It is not a fixed answer sentence and not a synonym for a TaskType.

---

# 1. Canonical set

G1 starts with **13 mother strategies**. New strategies require evidence that an existing one cannot express the needed procedure without losing diagnosis/intervention value.

## S1 — 证据—解释—结论链

```text
CN-S-evidence-explanation-conclusion
```

### Short chain

```text
结论需要什么证据
→ 找证据
→ 解释“为什么这条证据支持结论”
→ 回扣题目
```

### Core use
- 人物形象
- 主旨/情感判断
- 文体判断
- 开放评价
- 诗歌情感
- 文言人物/观点
- 简短论证

### Boundary
Do not use for pure retrieval or when the main problem is information compression rather than justification.

---

## S2 — 比较维度—分别取证—同异—意义

```text
CN-S-compare-dimension-evidence-significance
```

### Short chain

```text
先定比较维度
→ A取证
→ B取证
→ 写同/异
→ 解释差异/共同点的意义
```

### Core use
- 两文本比较
- 人物对比
- 诗歌比较
- 文言比较
- 写法比较
- 材料观点比较

### Boundary
“列出A和B”不等于比较；必须共享同一维度。

---

## S3 — 内容—位置—上下文关系—作用

```text
CN-S-content-position-context-function
```

### Short chain

```text
写了什么
→ 放在哪里
→ 与前后文什么关系
→ 对结构/人物/主旨产生什么效果
```

### Core use
- 段落作用
- 句子作用
- 标题作用的一部分
- 插叙/照应/铺垫
- 开头结尾作用
- 结构分析

### Boundary
不能只背“承上启下”；必须说明承什么、启什么。

---

## S4 — 定位—分类—合并—压缩

```text
CN-S-locate-classify-merge-compress
```

### Short chain

```text
找相关信息
→ 按同一标准分类
→ 合并重复
→ 保留必要条件后压缩
```

### Core use
- 信息提取
- 内容概括
- 原因概括
- 多材料整合
- 图文信息转述
- 文言事件概括

### Boundary
如果题目要求解释“为什么”，压缩之后通常还要接 S1 或 S13。

---

## S5 — 观点—理由—证据—论证—边界

```text
CN-S-claim-reason-evidence-warrant-boundary
```

### Short chain

```text
明确观点
→ 给理由
→ 给证据/例子
→ 解释证据如何证明理由
→ 加必要限定/边界
```

### Core use
- 议论段
- 开放评价
- 证据充分性
- 材料作文论证
- 多文本观点判断
- 反驳/补充观点

### Boundary
只列论据不算论证；只表态也不算。

---

## S6 — 景/事/人—关键词—情绪方向—对象—验证

```text
CN-S-poetry-evidence-emotion
```

### Short chain

```text
还原景/事/人
→ 圈决定性词语/意象
→ 判断情绪方向
→ 确定情感对象
→ 用原诗再验证
```

### Core use
- 古诗情感
- 意境
- 情景关系
- 人物状态
- 综合鉴赏的一部分

### Boundary
不允许直接把固定意象套成固定情感。

---

## S7 — 圈关键词—逐词落实—句式调整—补省略—通读校验

```text
CN-S-classical-translation-five-step
```

### Core use
- 文言翻译
- 译句复核

### Boundary
是翻译程序，不替代词义/句式 Knowledge 本身。

---

## S8 — 特殊情境—关键选择—差异—意义

```text
CN-S-special-context-key-choice-significance
```

### Short chain

```text
情境为什么特殊
→ 人物做了什么关键选择
→ 与常态/他人有什么差异
→ 这种选择为什么更能检验人物/中心
```

### Core use
- 典型事件
- 人物形象
- 选材作用
- 叙事写作选材迁移

### Boundary
普通事件概括不需要强行套此模型。

---

## S9 — 关键词句—写什么—怎么写—具体效果—意义

```text
CN-S-textual-appreciation
```

### Short chain

```text
抓关键词句
→ 说清写了什么
→ 判断语言/修辞/描写/角度
→ 解释具体表达效果
→ 回到情感/人物/主旨
```

### Core use
- 词句赏析
- 炼字
- 修辞效果
- 描写赏析
- 表现手法局部分析

### Boundary
不能停在“生动形象”；效果必须具体。

---

## S10 — 题目限制—核心任务—候选答案—逐项校验

```text
CN-S-parse-constraints-and-fit
```

### Short chain

```text
圈对象/范围/身份/文体/情境限制
→ 提炼核心任务
→ 生成候选立意/回答
→ 用限制逐项排除偏题
```

### Core use
- 作文审题
- 材料任务写作
- 微写作
- 情境表达
- 开放题审题

### Boundary
审题完成不等于立意/论证已经完成。

---

## S11 — 中心—典型材料—关键场景—细节—变化—点题

```text
CN-S-narrative-construction
```

### Short chain

```text
中心/主问题
→ 选典型事件
→ 找关键场景
→ 放人物/环境细节
→ 推进“我/人物”的变化
→ 回扣中心
```

### Core use
- 叙事作文构思
- 片段写作
- 人物故事
- 素材迁移

### Boundary
它是叙事建构母模型，不适合替代议论写作的 S5。

---

## S12 — 定位问题—保留原意—最小修改—复核

```text
CN-S-diagnose-minimal-revise-check
```

### Short chain

```text
先判断问题位置/类型
→ 保留原意
→ 做最小必要改动
→ 通读检查新问题
```

### Core use
- 病句修改
- 句子逻辑
- 作文局部修改
- 表达准确性

### Boundary
若中心/结构本身错误，需要先修高层问题，不能只润色句子。

---

## S13 — 现象/结果—关系类型—事实链—核心原因—回扣

```text
CN-S-relation-chain
```

### Short chain

```text
题目问的结果/现象是什么
→ 判断因果/条件/目的/转折等关系
→ 按关系找事实
→ 连成完整逻辑链
→ 回扣问题
```

### Core use
- 原因分析
- 条件分析
- 行为动机
- 情节因果
- 信息类文本关系分析
- 文言内容原因

### Boundary
如果需要评价证据是否足够，应转入 S5；如果只需压缩信息，优先 S4。

# 2. Strategy composition

A concrete Question may need more than one mother strategy.

Examples:

### 人物形象题

```text
S8 特殊情境—关键选择—意义
+
S1 证据—解释—结论
```

### 标题作用题

```text
S3 内容—位置—上下文关系—作用
+
S1 证据—解释—结论
```

### 古诗炼字

```text
S9 关键词句—写什么—怎么写—效果
+
S6 景/事/人—关键词—情感
```

### 文言原因概括

```text
S4 定位—分类—合并—压缩
+
S13 关系链
```

### 开放评价

```text
S10 审题约束
+
S5 观点—理由—证据—边界
```

Strategy composition must remain small. If a routine short-answer Question appears to require five mother strategies, the mapping or node decomposition is probably wrong.

# 3. Mother strategy lifecycle

For each Strategy node, training follows:

```text
理解原理
→ 提示下执行
→ 只提示策略名
→ 自主识别并调用
→ 限时/陌生材料自动调用
```

This maps naturally to C1:

- Mastery: can the learner execute the procedure correctly?
- Automation: does the learner know when to invoke it without being told?
- Complexity: at what demand can the strategy still work?

F2 H2 is often the explicit strategy reminder. A successful H2 response may support Strategy mastery but not independent A2/A3 self-trigger evidence.

---

# 4. What is not a mother strategy

Reject as Strategy nodes:

### Fixed answer shells

```text
“这句话运用了……，生动形象地……”
```

This is an output skeleton, not a reasoning procedure.

### Task labels

```text
人物形象分析
标题作用题
炼字题
```

These are TaskTypes.

### Atomic abilities

```text
找出关键句
判断情绪方向
```

These are Ability operations.

### Knowledge lists

```text
比喻/拟人/排比
文言实词义项
```

These are Knowledge.

---

# 5. G1 strategy-count discipline

Target operational catalog:

```text
approximately 10–15 mother strategies
```

Adding a 14th/15th strategy is acceptable only when:

1. it coordinates at least two operations;
2. it recurs across multiple Questions/materials;
3. it has a distinct failure pattern/intervention path;
4. it cannot be expressed as a composition/variant of an existing mother strategy without loss;
5. it can meaningfully acquire its own Mastery/Automation evidence.

The goal is not to hit an exact number. The goal is to prevent Strategy proliferation while preserving real procedural distinctions.
